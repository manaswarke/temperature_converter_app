# Temperature Converter Application

A robust Python utility designed to convert temperatures seamlessly between various scales, including Celsius, Fahrenheit, and Kelvin. This repository is structured to include both the uncompressed source code directory and a compressed deployment archive.

## 📁 Repository Structure

* **`p3_tc_app/`** – Main development directory containing the application's source modules, interface files, and operational logic.
* **`p3_tc_app.zip`** – A compressed archive containing the complete project folder structure for quick distribution, transfer, or local backup extraction.

## 🚀 Key Features

* **Multi-Scale Conversion:** Easily switch and convert calculations across Celsius, Fahrenheit, and Kelvin formulas.
* **Input Validation:** Automatically handles invalid inputs (like text characters or below absolute zero anomalies) to prevent runtime errors.
* **Clean Interface:** Provides clean, formatted output layouts for clear reading.

## 💻 Setup & Execution

1. Confirm that Python is installed and configured in your system environment path.
2. Download or clone this workspace repository locally.
3. If using the archive, extract the files from `p3_tc_app.zip`.
4. Open your terminal or console terminal inside the root directory.
5. Execute the primary application file by running:
   ```bash
   cd p3_tc_app
   python p3_tc_app.py
